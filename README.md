# Neon Strike

A fast-paced 2D top-down shooter in a single HTML file.

## Play

Open `neon-strike.html` in any modern browser. No build step, no dependencies.

- WASD / Arrow keys: move
- Mouse: aim
- Click (or hold on Hard): fire
- P / ESC: pause (change difficulty or quit)

## Difficulty

- Easy: slow enemies, 10 HP damage, slower fire
- Medium: balanced
- Hard: fast enemies, 5 HP damage, auto-fire when holding

## Features

- Neon visuals with glow, particles, parallax stars
- 3 difficulty levels selectable before play and mid-game
- Pause menu with difficulty switching
- Score, HP, levels, increasing enemy spawns
